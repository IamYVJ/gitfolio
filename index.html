Sign in with a token

Signing in lifts GitHub's limit from 60 to 5,000 requests an hour, so every repo gets scanned. On your own profile it also adds private repos and private contributions.

A static site can't do GitHub's OAuth login (that needs a server to hold a secret), so sign-in uses a personal access token. It stays in this browser and is only ever sent to api.github.com.

  1. Create a token: public data only ↗ or include private repos ↗
  2. Paste it here.
